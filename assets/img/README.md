# 图片放这里

把图片按下面的文件名放进这个文件夹，网站会自动显示；文件缺失时页面会显示一个虚线占位框，提示你应该放在哪里。

| 文件名 | 用在哪里 | 建议尺寸 |
| --- | --- | --- |
| `portrait.jpg` | 首屏个人照片 | 竖版，约 900 × 1100 px |
| `project-kunming-airport.jpg` | 昆明长水机场 T2 | 横版，1600 × 1200 px |
| `project-southbund.jpg` | 南外滩金融中心 | 横版，1600 × 1200 px |
| `project-sams-club.jpg` | 张家港山姆会员商店 | 横版，1600 × 1200 px |
| `project-airport-t2t3.jpg` | 淮安 / 大理机场航站楼 | 横版，1600 × 1200 px |
| `project-cfd.jpg` | CFD 项目群 | 横版，1600 × 1200 px |
| `og-cover.jpg` | 分享到微信 / 社交平台时的封面图 | 1200 × 630 px |
| `favicon.svg` | 浏览器标签页图标（已提供） | — |

小提示：

- 文件名想改成别的也行，只要同步修改 `data/content.js` 里对应的 `image:` 路径。
- 模拟云图、模型截图、效果图都可以，但注意不要在图上泄露业主未公开的项目信息。
- 图片建议压缩到 300 KB 以内（可用 [squoosh.app](https://squoosh.app)），页面会打开得更快。
