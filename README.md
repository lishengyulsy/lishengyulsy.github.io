# 李圣宇 · 个人网站（可自己维护版）

一个不需要任何框架、不需要装软件就能维护的个人介绍网站：**改文字只改一个文件**，其余代码不用碰。
中英文双语，手机 / 平板 / 电脑自适应，可以直接放到 GitHub Pages、Vercel、Netlify 或国内的对象存储上。

---

## 一、文件结构

```
personal-site/
├─ index.html              ← 页面骨架（一般不用改）
├─ data/content.js         ← ★ 所有文字、项目、链接都在这里改
├─ assets/
│  ├─ css/style.css        ← 配色、字体、间距（进阶修改）
│  ├─ js/main.js           ← 渲染逻辑（不用改）
│  ├─ img/                 ← 放照片和项目图（详见其中的 README）
│  └─ files/               ← 放简历 PDF
└─ README.md               ← 你正在看的这份说明
```

## 二、怎么在本地看效果

最简单：双击 `index.html`，用浏览器打开就能看。

更推荐（本地服务器方式，行为和线上一致）：

```powershell
cd outputs\personal-site
"C:\Users\lishe\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。改完 `data/content.js` 保存、刷新页面即可。

## 三、怎么改内容（只用改 `data/content.js`）

所有文案都是这种形式：

```js
title: { zh: '绿色建筑工程师', en: 'Green Building Engineer' },
```

`zh` 是中文版，`en` 是英文版。右上角按钮可以切换语言，语言偏好会记住。

常见修改位置：

| 想改什么 | 改哪里 |
| --- | --- |
| 姓名、职称、首页一句话介绍、首页数据 | `profile` |
| 关于我的段落与三个亮点 | `about` |
| 四张「专业方向」卡片 | `expertise.items` |
| **对外咨询服务**（服务项、合作方式、流程、CTA） | `services` |
| 项目经验卡片 | `projects.items` |
| 底部「其他参与项目」简表 | `projects.otherItems` |
| 工作经历 | `experience.items` |
| 教育背景 | `education.items` |
| 技能与认证 | `skills.groups` |
| 联系方式、LinkedIn 链接、简历文件 | `contact` |

**加一个新项目**：把 `projects.items` 里任意一个 `{ ... }` 整块复制一份，粘在末尾，改里面的内容就行。`featured: false` 的项目会自动变成底部简表样式。

**调整咨询服务**：`services.items` 是服务卡片，`services.engagement` 是「合作方式」列表，
`services.process` 是「合作流程」四步，`services.cta` 是底部那句邀约语。
如果以后想写清楚收费方式、驻场时长这类信息，也可以直接加在 `services.engagement` 里。

## 四、放照片

把图片放进 `assets/img/`，文件名对照 `assets/img/README.md` 里的表格。
没放图片时，页面上会显示一个虚线框，直接写着该图片应该叫什么名字，所以不用担心忘记位置。

## 五、换配色

打开 `data/content.js` 最上面的 `settings.theme`，改四个色值即可：

```js
theme: {
  accent: '#0F6B52',  // 主色：深绿
  accent2: '#B8863B', // 辅助色：暖金
  bg: '#F6F8F5',      // 页面底色
  ink: '#12211C'      // 正文颜色
}
```

想要更冷静的工程感可以试：`accent: '#12507B'`（蓝）+ `accent2: '#3F8F79'`（青绿）。

## 六、我预留的扩展位（要用的时候打开就行）

在 `settings.sections` 里：

| 开关 | 作用 |
| --- | --- |
| `insights: true` | 显示「观点分享」区块，可放技术文章、项目复盘、演讲、课程 |
| `cvDownload: true` | 顶部出现「下载简历」按钮（记得先把 PDF 放进 `assets/files/`） |
| `otherProjects: false` | 隐藏底部「其他参与项目」简表 |
| `wechat: true` | 在联系方式里显示微信号（需要先在 `contact.wechat` 填写） |
| `phone: true` | 在联系方式里显示手机号（**默认关闭**，见下面的隐私提醒） |

## 七、怎么发布上线（GitHub Pages + 国内也能顺畅打开）

这个网站是纯静态文件，同一份文件可以同时放到多个平台，互不冲突。推荐「一个源站 + 一个国内入口」的组合：

**第 1 步：GitHub Pages（免费，作为主站和海外入口）**
把 `personal-site` 文件夹里的文件传到 GitHub 仓库 → 仓库 Settings → Pages → Source 选 `main` 分支、根目录 → 得到 `https://用户名.github.io/仓库名/`。
`github.io` 在国内大部分时间能打开，但速度和稳定性时好时坏，所以别只放这一份。

**第 2 步：加一个国内访问入口（二选一）**

| 方案 | 是否需要备案 | 国内速度 | 说明 |
| --- | --- | --- | --- |
| 云厂商对象存储静态网站（腾讯云 COS / 阿里云 OSS），选**香港或新加坡**节点 | 不需要 | 较好 | 把同一份文件上传，开启静态网站功能即可，能得到一个自己的域名 |
| 云厂商对象存储 / CDN 的**国内节点** | 需要域名备案 | 最好 | 速度最快，但要先买域名并完成备案，通常 1–3 周 |

如果只是想让国内朋友和甲方打开不卡，**香港节点 + 自己的域名**是最省事的组合。
同一个域名也可以同时解析到 GitHub Pages，用不着维护两套内容——每次改完 `content.js`，把整个文件夹重新上传一次即可。

> 两点提醒：
> 1. 据我目前了解，Vercel 的 `vercel.app` 默认域名在国内经常打不开，Netlify 也不稳定；Gitee Pages 的免费政策近年有调整，用之前建议先确认现状。这些平台的国内可达性会变，**上线前最好用手机流量实测一次**。
> 2. 上线前把 `index.html` 里的 `og:image`（分享封面，建议 1200×630）、`og:title` 和 meta 描述换成你自己的信息，分享到微信和领英才会显示正确的标题与封面。

## 八、隐私提醒

- 手机号默认**不显示**。公开页面很容易被爬虫抓取，如果确实需要，建议改成「加微信」或只放邮箱。
- 简历里提到的项目名称请确认没有保密限制；涉及业主未公开的项目，建议把名称脱敏成「某超高层办公综合体」「某三甲医院院区」。
- 模拟云图、模型截图同样属于可能涉密的内容，发布前请自行确认。
